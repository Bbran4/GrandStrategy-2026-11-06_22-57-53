# Starter tree meshes

The meshes come from [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The original GLBs are mirrored in [Hidencod/tge-assets](https://github.com/Hidencod/tge-assets/tree/main/packs/nature-kit). The OBJ files separate each source model into crown and trunk and normalize the pair to the same ground origin and height.

| Species slot | Source model | Use |
| --- | --- | --- |
| Oak | tree-oak | Oak |
| Birch | tree-thin | Narrow deciduous stand-in |
| Spruce | tree-pinetalla-detailed | Tall conifer stand-in |
| Stone pine | tree-pineroundc | Rounded pine stand-in |
| Olive | tree-small | Small broadleaf stand-in |
| Acacia | tree-plateau | Flat-canopy stand-in |
| Palm | tree-palmdetailedshort | Palm |
